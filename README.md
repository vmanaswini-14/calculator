# Calculator Web App

## 📌 Description
This project is a simple Calculator Web Application built using HTML, CSS, and JavaScript.  
It allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division through a simple interactive interface.

The project demonstrates basic frontend development and JavaScript logic.

## 🚀 Features
- Perform basic arithmetic operations
- Interactive calculator buttons
- Real-time display of input and results
- Clean and simple user interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
calculator-app/
│
├── index.html
├── style.css
├── script.js
└── README.md

## ▶️ How to Run
1. Clone or download the repository
2. Open the `index.html` file in any web browser
3. Use the calculator buttons to perform calculations
